# Public Positioning Guide

## One-line description

ARC-Apache is a binary-first memory and proof substrate for local AI systems, storing large payloads, language graphs, visual memory, model artifacts, and runtime events as cryptographically verifiable objects.

## Short description

ARC-Apache turns ARC's event/receipt architecture into a content-addressed binary memory plane. Every durable object is serialized to bytes, chunked, hashed, Merkle-rooted, registered by receipt, and exposed back to humans and models through regenerated views.

## What to say publicly

Use confident but falsifiable language:

- deterministic binary object storage;
- cryptographic proof chain;
- local-first AI memory;
- receipt-backed runtime state;
- language-module provenance;
- visual memory payloads;
- seeded reconstruction references;
- model/dataset lineage.

## What not to claim yet

Do not claim:

- finished AGI;
- military/DARPA affiliation;
- unbreakable encryption;
- production cryptographic signing before keys are implemented;
- automatic truth discovery;
- model improvement without benchmark receipts;
- universal compression of arbitrary data.

## Fiction-inspired note

If referencing cinematic or TV inspirations, frame them as aesthetic/doctrinal inspiration only. Do not imply affiliation, ownership of fictional IP, or use of protected names/logos in public repo branding.

Recommended wording:

> Inspired by fictional ideas of memory recall, deterministic replay, and provenance-aware intelligence systems, ARC-Apache implements an ethical, local-first, developer-owned binary proof spine.
