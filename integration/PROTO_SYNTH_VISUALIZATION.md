# Proto-Synth Visualization Contract

Proto-Synth should visualize ARC-Apache data as graph surfaces:

- manifest node
- payload/envelope hash node
- Merkle root node
- chunk fan-out
- receipt chain
- signature/trust state
- stream sequence timeline
- language lineage graph
- LLMBuilder promotion lineage

Proto-Synth is a visual shell, not the authority. Authority remains ARC-Core.
